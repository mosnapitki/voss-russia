# VOSS AR

Готовая AR-страница для GitHub Pages.

## Публикация

1. Откройте репозиторий `mosnapitki/voss-russia`.
2. Загрузите в корень репозитория файлы `index.html` и `voss-bottle.glb`.
3. GitHub → Settings → Pages.
4. В разделе Build and deployment выберите `Deploy from a branch`.
5. Branch: `main`, Folder: `/ (root)`.
6. Сохраните настройки.

После публикации адрес будет:

https://mosnapitki.github.io/voss-russia/

QR-код можно направить именно на этот адрес.

## Как работает

QR → GitHub Pages → «Запустить AR» → камера → 3D-бутылка VOSS.

На iPhone нужен Safari и разрешение камеры; на Android поддерживаемый браузер.
